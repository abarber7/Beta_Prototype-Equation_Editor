## 📌 Project Overview

This project is a **beta prototype** of a browser-based **LaTeX math equation editor**, built to offer users a lightweight, responsive interface for writing and rendering math expressions in real-time using **MathJax**. The tool is ideal for students, educators, and developers who frequently work with LaTeX equations and want a fast, distraction-free workspace.

---

## ✨ Features

- 📄 Live rendering of LaTeX-formatted equations
- 🖊️ Clean and minimalist text editor layout
- 🔄 Real-time preview with MathJax rendering
- 💡 Supports inline `\( ... \)` and block `\[ ... \]` math modes
- 💻 Works entirely in the browser — no server required
- ⚙️ Easily extendable for future feature integration (copy/export/save)
